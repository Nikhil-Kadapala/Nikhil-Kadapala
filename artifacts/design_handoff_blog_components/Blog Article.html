Research note · 2026-08-29

The score is not the work.

Nikhil Kadapala · 9 min read

A high metric can still describe a system nobody can use. That distance — between a plausible answer and a useful one — is most of what I work on.

The claim

Automatic scores are useful fixtures, not verdicts. A benchmark tells you a model cleared a bar someone drew in advance; it does not tell you the bar was in the right place. I keep running into agents that post a good number and still fail the person waiting on the answer.

That gap is the actual research problem. Everything below is one attempt at closing it — a harness, a failure mode, and the parts I still don't have an answer for.

Note

"It felt pretty good" is not a metric. Everything in this note is measured against a fixed rubric checked into the repo, not a vibe check after the fact.

Evidence, not vibes

I built a small run inspector to make every claim checkable after the fact: what the agent retrieved, what it did with it, and whether the final answer still points back to real evidence.

Watch it end to end rather than reading a transcript — the delay between steps is part of what's being measured.

A minimal harness

The scoring function is deliberately small — under thirty lines. Complexity in the harness is where evaluation bugs hide.

eval/score.py
def score_response(answer, evidence):
    # fails closed: no evidence span, no credit
    if not evidence:
        return 0.0

    covered = [e for e in evidence if e.span in answer.citations]
    return len(covered) / len(evidence)

Zero dependencies, on purpose. Anything the harness imports is one more thing that can silently change the score between runs.[1]

Where it fails

The harness rewards citation coverage, not correctness of the citation itself. An agent that cites the right paragraph for the wrong reason still scores well. I haven't closed this hole yet.

Caveat

Coverage went from 0.61 to 0.87 after I added the citation check — and the failure rate reported by human reviewers barely moved. The metric got better before the work did.
