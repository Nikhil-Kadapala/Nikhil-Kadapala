Two work units

Unit A

Conventions check

Rules oxlint does not express. Same pattern as scripts/check-agent-index.sh: a bash check, plus a small fixture test, then one step in the existing CI job.

  1. No raw hex in .tsx (not .ts; shiki stays legal)
  2. No text-[Npx]
  3. No className={\`, className concat, or cn(\`
  4. Every page.tsx has metadata or generateMetadata with a non-empty description

Unit B

PR template

None exists under .github/ today. Add one file so every PR starts with the same review list.

  • What changed / why / how to test
  • typecheck + lint + build + conventions
  • One wave only
  • No hex / arbitrary px / string-built classNames
  • Metadata includes description
